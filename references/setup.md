# 第一次用和装软件

这个文件管三件事：开工检查标「要处理」的软件怎么装；第一次用（开工检查提示「还没设置用户目录」）要做的「基础工作准备」和「建用户目录」；挖竞品外链前 DataForSEO 账号的说明。开工检查本身的步骤在 SKILL.md「开工检查」。名词见 SKILL.md「名词」。

## 装软件（开工检查标「要处理」的）

每个系统只有一种装法，装完要重开 AI 平台才找得到。装库和装浏览器工具的官方源在国外，脚本按固定规则切国内镜像：官方源通就用官方源，官方源连不上或装到一半失败就换镜像（pip 用清华镜像，npm 用 npmmirror），不用 AI 挑。标「要处理」的逐条处理：

- **Python 没有或版本太老**（要 3.9 或更新）：告诉用户要装 Python。
  - Windows：`winget install Python.Python.3.13`，用户同意后 AI 代跑。winget 下载失败（国内没 VPN 常见）就从国内镜像 `https://registry.npmmirror.com/-/binary/python/` 进最新的 3.13.x 文件夹下载 `python-3.13.x-amd64.exe`，AI 代跑 `.\python-3.13.x-amd64.exe /quiet PrependPath=1` 静默装。
  - Mac：到 python.org 下载 macOS 安装包（.pkg），用户自己双击装（要输电脑密码，AI 代跑不了）。python.org 打不开就从上面那个镜像的同一个文件夹下载 `python-3.13.x-macos11.pkg`。
- **库装不上**：官方源和国内镜像都试过才会报，把打印的 pip 报错给用户看，商量怎么装。
- **Node.js 没装或太老**：按打印的那一种装法装（Windows `winget install OpenJS.NodeJS.LTS` 用户同意后 AI 代跑；Mac 用户自己装 nodejs.org 的 .pkg；官方源下载失败就按打印的国内镜像地址下载安装包），装完重开 AI 平台再查。「浏览器工具」要用它。
- **Chrome 没装**：按打印的装法装（Windows `winget install Google.Chrome` 用户同意后 AI 代跑；Mac 用户自己从 google.cn/chrome 下载 .dmg 装，国内不用翻墙）。「浏览器工具」用电脑上的 Chrome 开一个单独的档案，不另下浏览器。
- **联网连不上**：全都连不上多半是 AI 平台没给命令联网的权限（沙箱），请用户在平台设置里打开；官方源连不上、国内镜像通的，脚本已打印后面用哪个镜像，照着做；只有 DataForSEO 连不上只影响菜单 1。
- **用户目录写不进去**：请用户在平台设置里允许 AI 读写这个文件夹。

标「提醒」的不是要装的东西，各怎么做见 SKILL.md「开工检查」第 2 条。

## 浏览器工具：Playwright MCP

浏览器工具固定用 Playwright MCP（微软出的浏览器 MCP，SKILL.md 开头列的平台都能加）。第2、3、5、6步看页面、注册登录、填表提交都用它：它开的是单独的浏览器，碰不到用户自己浏览器里的邮箱、cookies 和密码；外链网站的登录状态存在它自己的档案里，关掉再开还在。SKILL.md「开工检查」第 3 条查出没装时按下面装，装完重启平台（或重新加载 MCP），工具列表里出现 `browser_` 工具才算装好：

- 前提是 Node.js 18 或更新、电脑上装了 Chrome（开工检查都查过）。
- 在平台的 MCP 设置里加一个服务器：名称 `playwright`，命令 `npx`，参数 `@playwright/mcp@latest`。能贴 JSON 的入口贴标准写法：`{"mcpServers": {"playwright": {"command": "npx", "args": ["@playwright/mcp@latest"]}}}`。开工检查打印「npm 官方源连不上、国内镜像通」时，多加一个环境变量 `npm_config_registry` = `https://registry.npmmirror.com`（JSON 里加 `"env": {"npm_config_registry": "https://registry.npmmirror.com"}`），npx 就从国内源取包。各平台的入口：Claude Code 跑 `claude mcp add playwright -- npx @playwright/mcp@latest`；Codex 跑 `codex mcp add playwright -- npx @playwright/mcp@latest`；Claude 桌面版在 设置 → 开发者 → 编辑配置 打开的文件里加；WorkBuddy 在技能菜单的设置 → MCP 配置 → 编辑 mcp.json 里加，保存后到连接器管理里点启用；豆包电脑版在「技能·连接器·伙伴」→ 新建 → 新建自定义连接器，传输方式选「本地命令 / stdio」；MiniMax Code 在设置的 MCP Server 配置里加；千问办公在「扩展」的连接器里选自定义 MCP；DeepSeek Harness 按它的 MCP 文档加一个 stdio 服务器。
- 平台的添加入口只收网址、不能填命令的：后台跑 `npx @playwright/mcp@latest --port 8931`，网址填 `http://localhost:8931/mcp`。
- 装不上（平台不让加 MCP、电脑禁装软件）：告诉用户第2、3、5、6步做不了，等用户解决，不换别的办法；没打开过的页面不许当成看过。

## 基础工作准备（第一次用）

开工检查打印「还没设置用户目录」就是第一次用，先把这一环做完再做别的。这一环不用用户给任何东西：不建用户目录、不发外链，也不问用户的独立站、竞品和 DataForSEO 账号（用户自己先说了的记下来，建完用户目录直接用，不再问）。按下面几项建待办（用平台的待办工具；没有就在回复里列清单），做完一项标一项：

1. **装依赖**：照「装软件」处理，直到开工检查没有标「要处理」的（「还没设置用户目录」这条提醒留到「建用户目录」处理）。
2. **装浏览器工具**：照「浏览器工具：Playwright MCP」装。装好后用它打开 `https://example.com`，`browser_snapshot` 看到页面标题「Example Domain」才算能用。试完用 `browser_close` 关掉浏览器。
3. **打开 SKILL 自带的外链报告**：用用户自己的默认浏览器打开 SKILL 目录的 `assets/report/外链报告.html`（Windows 在 PowerShell 跑 `Start-Process "<文件完整路径>"`，Mac 跑 `open "<文件完整路径>"`）。里面只有 SKILL 默认外链库，不用用户目录。平台打不开本机文件的，告诉用户双击这个文件看。
4. **基础说明**：照下面给用户讲一遍，最后一行问用户目录放哪。

结束边界：开工检查没有标「要处理」的；浏览器工具打开过 example.com；SKILL 自带的外链报告打开过；基础说明讲过了。讲完就停下，等用户给了文件夹路径再做「建用户目录」。

**基础说明**（照下面的格式和内容讲，只讲这三块，不加别的）：

```text
一、这个 SKILL 帮你做什么
1. 挖竞品外链：找出竞品在哪些网站有外链
2. 判断能不能发：免费、付费，还是发不了
3. 帮你发外链：AI 自己注册、填表、提交
4. 回访收录：提交后每天检查对方收录没有

二、资料和账号安全
1. 你的资料都放在用户目录，就是你指定的一个文件夹，只存在这台电脑上
2. SKILL 更新、重装都不会丢资料，请定期备份用户目录
3. AI 在单独的 Chrome 窗口里操作，碰不到你自己浏览器里的账号和密码

三、外链报告
1. 刚才打开的是 SKILL 自带的外链报告，只有内置外链库
2. 用户目录建好后，会给你打开你自己的外链报告

下一步：告诉我用户目录放在哪个文件夹（给完整路径）
```

大标题、「下一步」加粗。发外链要准备什么、哪些事要用户点头、每天发多少，到了那一步再讲，这里不讲。

## 建用户目录（第一次用，讲完基础说明后）

用户给了文件夹路径就做，同样建待办：

1. **建用户目录**：跑菜单 6（第二行：文件夹完整路径）。菜单 6 建好用户目录，拷好用户档案说明、设置和一个空的 DataForSEO 账号文件，再生成 `外链报告.html`（这时只有外链库，还没有独立站）。已经有东西的目录照样能用，里面的东西不动。重装电脑或换了用户文件夹后，用原来的用户目录再跑一次菜单 6 就接上了。
2. **再查一遍**：再跑一次开工检查，没有标「要处理」的，也不再提示「还没设置用户目录」。
3. **打开外链报告网页**：后台跑菜单 10（见 SKILL.md「怎么跑程序」），网页会在用户自己的默认浏览器里打开。平台不能后台跑命令的跳过这步，告诉用户双击用户目录里的 `外链报告.html` 看（只能看，数据是上次生成时的）。

结束边界：用户目录第一层有 `外链报告.html`；开工检查没有标「要处理」的，也不再提示「还没设置用户目录」；外链报告网页打开过（平台不能后台跑命令的除外）。做完跟用户说用户目录建在哪（写真实路径）、`用户档案说明.txt` 讲了里面都有什么、`data` 文件夹不用管，最后一行写「**下一步**：告诉我你的独立站和要挖的竞品网址」。用户前面已经给过独立站、竞品的，不再问，直接接着做。

## DataForSEO 账号（挖竞品外链前）

用户提到要挖竞品网站的外链（或者给了要挖的竞品），而开工检查提示「DataForSEO 账号还没填」时，把下面这段原样发给用户。账号已经填好的不用发；用户没提挖竞品，就不提 DataForSEO 这些事。

```text
DataForSEO API：一个国外专业的SEO类的API服务商，挖竞品网站的外链才需要，不挖就不用填。
1、DataForSEO API 一次可以挖最多1000条外链。
2、新用户注册赠送1美金额度，大概够免费查15次左右；充值则最低要充50美金，自己考虑。
3、DataForSEO还提供其他SEO数据服务，有兴趣自己问AI。

其他选择：
1、如果你有自己的挖竞品网站外链的工具，直接告诉AI即可
2、Ahrefs免费外链查询页：每次只给链接最强的前 100 条外链，没有接口，只能在网页上看
3、免费的Bing站长工具：能看竞品的外链，还能导出表格，但导出的不全。前提是得先把自己的独立站在 Bing 站长工具里验证好。
4、如果你实在不知道怎么做，那就等开发者更新更多外链库吧。
```

用户接着问或选了以后：

- **用 DataForSEO**：注册在 https://app.dataforseo.com/register 。登录后在 https://app.dataforseo.com/api-access 找 API login 和 API password，粘贴到开工检查打印的那个账号文件（默认 `<用户目录>/data/dataforseo.txt`）里「DataForSEO_API_login=」「DataForSEO_API_password=」的等号后面保存，不用发给 AI。AI 帮用户打开这个文件：Windows 跑 `notepad "<文件完整路径>"`，Mac 跑 `open -e "<文件完整路径>"`。
- **问价格**：每查一次 0.024 美元 + 每条外链 0.000036 美元，一次最多 0.06 美元；给竞品页面网址查两次（页面、域名各一次），只给域名查一次。每次查之前都先问用户。
- **用自己的工具**：照 analyze.md「换外链数据工具」改程序。
- **用 Ahrefs 免费查询页或 Bing 站长工具**：用户确认要用，AI 当场自己解决。
- **等开发者更新外链库**：不挖，也不催。
