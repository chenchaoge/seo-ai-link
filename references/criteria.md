# 外链可用性分类标准

目标：判断竞品外链所在的页面，能不能也给独立站留下网址。链接是不是 dofollow 不影响分类，只记录在表里。名词（独立站、外链网站、竞品、外链库）见 SKILL.md「名词」。

## 结论（四选一）

- **免费类**：能留下链接，而且没写要收钱。有提交入口、哪里都没写收费的，默认就是免费类。再按下面的分组细分。
- **付费类**：写明了只能花钱留：付费提交、付费收录、sponsored 推广位、提交页只有价格没有免费选项。有免费选项就不算付费。
- **不可用**：有明确证据证明留不了。只认这几种证据：
  - 页面已不存在（404/410），或浏览器也打不开。
  - 竞品链接在评论区，但评论已关闭。
  - 竞品链接在正文里（编辑写的文章或新闻），页面上没有提交、注册、评论这类入口。
  - 自动生成的网站估值/whois 页。
  - 版规或发帖规则写明禁止外链（依据里写规则原文）。
  - 外链网站本身坏了或没有自助入口（清单见 SKILL.md「铁律」）：登录、注册、提交返回服务器错误；人机验证控件不显示；激活邮件收不到；支付失败；联系邮箱一直没配好；整站被封；表单必填项的选项是空的；只能加站长微信这类线下渠道。
  - 下面「看着能留、其实留不了」的几种情况。
- **无法判断**：还没看到有没有留网址的入口，或者看到了价格却看不出有没有免费档，才归这里。比如：页面上只有登录/注册按钮，看不出登录后能做什么；提交页有价格也有 free 字样；竞品链接在侧边栏或页脚；页面上找不到竞品链接；页面靠脚本加载或被拦截，看不到有没有入口。证据不够判不可用的，也归这里。已经看到提交入口、只是要登录后或点下一步才知道价格的，不归这里，按默认判免费类。

## 免费类再分两个维度

免费类每个外链网站都要同时定这两项，写进外链库的 `group` 和 `site_type`（复核结论里是 `final_group` 和 `final_site_type`）。付费类、不可用的两项都是 null。

**发外链方式（group）**：拿到链接要不要先有账号。

1. **直接提交**：免登录表单、发邮件、推荐入口，不用账号。
2. **注册账号提交**：要先有账号才能提交或发内容。邮箱注册和谷歌、GitHub、X、微信这类第三方登录都算这一组；用哪个账号按 accounts.md「注册登录用哪个账号」的顺序选，页面上看到的登录方式写进需人工核验。

**业务类型（site_type）**：外链网站是什么站，决定独立站的链接长在什么页面上。

1. **要挂回链或徽章**：要先在独立站挂对方的链接或徽章才收录。只要有这个要求就归这类，不管它本身是不是导航站。
2. **导航与产品发布类**：工具目录、AI 导航站、产品发布/榜单站、软件替代品库、awesome 清单。链接长在对方给独立站建的收录页上。
3. **社区论坛类**：论坛、社区、问答站、评论区。链接长在用户发的帖子、回答、评论里，内容归对方平台管、会被删。
4. **自建类**：用户自己的 GitHub 仓库、Hugging Face 资料、各平台个人主页的网址栏、自己开的博客。内容完全自己掌控，不用等审核。
5. 四种都装不下、又确认可用的，才考虑加新类型。加新类型必须先问用户，用户点头才加（加进 `scripts/modules/classifier.py` 的 SITE_TYPES 和这一节）；用户没点头之前 site_type 留 null，原因写进 final_check。

谁来定：第1步脚本能看出来的自动填（要求回链 → 要挂回链或徽章；已知平台按 `scripts/config.py` 的 KNOWN_PLATFORMS；提交页有表单、邮件、PR 入口的默认导航与产品发布类；评论区 → 社区论坛类）。第2步人工复核免费类时两项都必须写。第5步提交前再核对一遍，跟实际不符就改，第1～4步没定下来的在这里定。

## 所属行业（赛道）

外链网站本身是做哪个行业的。每个外链网站都要定一个（免费类、付费类、不可用都要），写进外链库的 `industry`；一批外链网站的行业写进那一批分析结果目录的 `industries.json`（见 data.md「所属行业：从挖掘到发外链」）。独立站也定一个，写进 profile.json 的 `industry`。

可选值（前 24 个参考 Similarweb 一级分类，用户定稿；同一个赛道大类里的行业互为相近赛道；行业之间用「；」隔开，括号里是举例）：

| 赛道大类 | 行业 |
|---|---|
| 科技 | AI产品工具；计算机、电子与科技（编程开发、网站建设、网络安全、数码电子）；加密货币与区块链 |
| 商业 | 商业与消费者服务（营销广告、SEO、卖外链的站群、物流、房地产、出版印刷）；电商与购物（电商平台、优惠券、比价）；金融；求职与职业；法律与政府 |
| 文娱 | 艺术与娱乐（音乐、影视、动漫、视觉设计、图书）；游戏；新闻与媒体；体育 |
| 知识 | 科学与教育；参考资料（词典、百科、地图） |
| 生活 | 社区与社会（信仰、公益、婚恋）；健康；生活方式（美妆、时尚、珠宝、婚礼）；餐饮；家居与园艺；爱好与休闲；宠物与动物；旅游；交通工具 |
| 工业 | 重工业与工程 |
| 不分行业 | 综合导航站；综合论坛博客 |

怎么判：

1. 看外链网站本身做什么、内容围绕哪个行业，不看竞品是谁、也不看独立站是什么。
2. 只做一个行业的归那个行业，不管它是导航、新闻、博客还是招聘：明确只收 AI 产品的导航站、只报 AI 新闻的网站、只招 AI 岗位的招聘站都是 AI产品工具，不算综合导航站；开发者社区、技术博客是计算机、电子与科技。
3. 什么行业都收的按功能归：综合导航目录、产品发布平台 → 综合导航站；论坛、问答、博客平台、社交媒体这类用户自己发内容的平台 → 综合论坛博客；综合新闻（含新闻稿转载）→ 新闻与媒体；综合招聘 → 求职与职业；综合优惠、电商 → 电商与购物。
4. 看不出来先看 DataForSEO 记的页面标题（程序打印的清单里带着），还拿不准就打开首页看标题和介绍；网站打不开的按页面标题和域名判。
5. 清单都装不下的，先问用户要不要加新行业，用户点头才加（加进 `scripts/config.py` 的 INDUSTRY_GROUPS 和上面的表）；没点头前先不写，原因在回复里说清楚。

**赛道关系**（外链网站对某个独立站，程序按两边的所属行业自动算）：

- 同赛道：行业相同。
- 相近赛道：行业不同，但在同一个赛道大类里。
- 不分行业：外链网站是综合导航站、综合论坛博客。
- 其他赛道：剩下的。
- 行业未标：外链网站或独立站还没定所属行业，先补上。

同赛道、相近赛道、不分行业合称契合赛道。发外链先发契合赛道的，其他赛道的先给用户看、用户定了才发，先后细则见 submit.md「发外链原则」。

## 需人工核验

大类已经确定、细节还要人去确认的（登录方式、收录条件、价格等），保留大类，在 `final_check` 写明要核验什么（自动预判写在 `auto_check`），不归无法判断。按默认判成免费类的（有入口、没写收费），要写「提交时看清有没有付款步骤」。

## 看着能留、其实留不了（判不可用）

- 竞品链接是作者写在正文里的：页面有评论框能填网址也不算入口，评论要登录也一样。竞品不是靠评论拿到这个链接的，评论里的链接一般也是 nofollow。
- 评论者名字只链到平台个人主页（比如 Substack 主页），链不到独立站。
- 自动搬运的镜像帖（比如 hacker_news 镜像版块）：链接 nofollow，版块没人看。
- 靠提 PR 加链接，但外人提的 PR 从来没被合并过。
- 只能装手机 App 或插件才能操作（本 SKILL 不装软件）。
- 登录或提交要关注微信服务号、公众号。

## 复核时怎么判

1. 先看竞品链接在页面哪里（评论、帖子、资料、正文、侧边栏），它是怎么留上去的，就照着找同样的入口。
2. 能留的位置要亲眼看到：输入框、"网站"栏、个人资料里的网址栏、发帖编辑器的链接按钮。自建内容还要看竞品同类页面的源代码，确认链接会显示出来、有没有 nofollow。
3. 判免费类必须同时写发外链方式和业务类型；要挂回链或徽章的业务类型就是「要挂回链或徽章」。要登录的都是「注册账号提交」，看不出能用什么账号登录的，需人工核验写「确认登录方式」；提交页看不到表单（靠脚本加载、只提到 App）的，先分到「直接提交」，需人工核验写「确认提交方式」。
4. 定大类看外链网站写明了什么：
   - 有提交入口（提交按钮或链接、填网址的表单、写明发邮件或提 PR 提交），哪里都没写要收钱：免费类。
   - 写明要收钱（每个收录都收费、只有付费方案）：付费类。
   - 有价格也有免费字样，看不出有没有免费档：无法判断，复核时去看清有没有免费档。
   - 看不到的步骤不算收钱的证据：要登录后才看到表单、要先点「分析」「下一步」才出价格的，照样判免费类，需人工核验写「提交时看清有没有付款步骤」。不为了看价格去点会把独立站网址交上去的按钮。
   - 只是「可能」的信号（有人机验证、像是只收某类产品、提到下载 App）只记进需人工核验，不改大类。
5. 不用局部经验做整体判断：某个外链网站上见过的情况只说明那个外链网站；这一轮同类外链网站多数怎样，不能拿来判别的外链网站。
6. 同一个外链网站多个页面结论应该一致，有差异要在依据里说明原因。
