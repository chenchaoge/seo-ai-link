用户档案说明
============

这个文件夹是你的「用户目录」，里面全是你自己的资料。外链 SKILL 只在你的电脑上读写它。

一、里面有什么
- 外链报告.html：外链报告，双击打开看。平时只用看它。
- data 文件夹：程序用的数据，平时不用打开。
  - data/report：外链报告网页用的样式、脚本和数据。报告打开要靠它，别单独挪走。
  - data/sites：你的独立站资料（介绍、发外链专用的邮箱和密码、logo），和每个独立站的提交台账（在每个外链网站上发到哪一步）。
  - data/library：你自己新挖掘、更正过的外链库。
  - data/analyses：每次查竞品外链的结果（从 DataForSEO 花钱买来的数据、复核结论、日志）。
  - data/settings.json：你的设置（当前独立站、默认竞品等）。
  - data/dataforseo.txt：DataForSEO 账号。只有挖竞品网站的外链才要，双击打开，把 API login、API password 分别粘贴到两行的等号后面，保存就行，不用发给 AI。

二、请保管、备份好
- 这些资料只有这一份。文件夹被删、硬盘损坏，独立站资料、发外链进度、自己挖掘的外链库都会丢失，无法找回。
- 建议定期把整个用户目录复制一份到别的硬盘或网盘。
- 更新或重装外链 SKILL 不会动用户目录。换电脑（Windows、Mac 都行）时把整个用户目录拷过去，再让 AI 重新设置用户目录（菜单 6）指向它，就能接着用。
- 用户目录里都是你自己的资料，请自己保管好，不要发给别人，也不要对外公开。

三、资料只在你的电脑上
- 这些资料都保存在你的电脑本地。外链 SKILL 不会把它们上传或同步到任何服务器、网盘，也不会放进 SKILL 目录（SKILL 目录分享出去时不带任何用户资料）。


四、关于挖竞争对手外链的方法

DataForSEO API：一个国外专业的SEO类的API服务商，挖竞品网站的外链才需要，不挖就不用填。
1、DataForSEO API 一次可以挖最多1000条外链。
2、新用户注册赠送1美金额度，大概够免费查15次左右；充值则最低要充50美金，自己考虑。
3、DataForSEO还提供其他SEO数据服务，有兴趣自己问AI。

其他选择：
1、如果你有自己的挖竞品网站外链的工具，直接告诉AI即可
2、Ahrefs免费外链查询页：每次只给链接最强的前 100 条外链，没有接口，只能在网页上看
3、免费的Bing站长工具：能看竞品的外链，还能导出表格，但导出的不全。前提是得先把自己的独立站在 Bing 站长工具里验证好。
4、如果你实在不知道怎么做，那就等开发者更新更多外链库吧。
